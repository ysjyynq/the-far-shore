# The Far Shore

An interactive winter experience on a floating island beneath a procedural galaxy, built with Three.js and TSL. Frosty plants, rippling water, shifting night skies, and ambient music.

## Open

Visit the published GitHub Pages site. To preview locally, open the website folder in VS Code and launch `index.html` with Live Server.
